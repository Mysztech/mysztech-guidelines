1. Go to **Settings > Order Display** to manage the order displays connected to the POS system. If no display has been paired, the message **“No order displays paired”** will appear.

![](/admin/7.Settings/Screenshot-2026-11-25-154806.png)\
2\. Tap **Pair Display** to pair an order display with the POS system.

3\. Once paired, the display will appear in the list. You can view its assigned department, address, and availability status.

![](/admin/7.Settings/Screenshot-2026-11-25-154602.png)

4\. Use the **toggle switch** to enable or disable the paired display. When enabled and connected, the display will show **Enabled, Paired,** and **Connected.**

![](/admin/7.Settings/Screenshot-2026-11-25-154750.png)5. Tap **Refresh** to update the display list and check its latest availability status.
